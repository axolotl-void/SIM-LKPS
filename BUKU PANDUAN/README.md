# Buku Panduan Pengguna SIM-LKPS

Panduan pemakaian **SIM-LKPS** (Sistem Informasi Manajemen Laporan Kinerja Program Studi,
instrumen LAM INFOKOM 2.1) untuk dosen dan operator program studi.

| Berkas | Untuk apa |
|---|---|
| `Buku-Panduan-SIM-LKPS-2026.docx` | Versi yang bisa disunting (Word) |
| `Buku-Panduan-SIM-LKPS-2026.pdf` | Versi siap dibagikan / dicetak |

**Isi:** 37 halaman, 6 bab.

1. Mulai Menggunakan — login, peran akun, istilah, bagian layar, urutan menu
2. Pola Pengisian — tiga pola tombol yang dipakai di semua tabel
3. Cara Mengisi Tiap Tabel — 32 tabel LKPS kriteria 1–6, tiap tabel bergambar
   formulir isian beranotasi nomor
4. LED dan Penilaian — 92 bagian LED (BAB I–III), matriks penilaian, bukti, ekspor
5. Kalau Ada Masalah — gejala, penyebab, tindakan
6. Lampiran — daftar periksa 32 tabel + alur kerja 8 minggu

**Aplikasi:** https://lkps.zegika.com

## Catatan untuk pemelihara

Semua gambar di dalam buku adalah tangkapan layar asli dari aplikasi, dengan kotak
bernomor yang menempel pada kolom isian. Kalau tampilan aplikasi berubah, gambar
perlu direkam ulang — jangan disunting manual, karena kotak anotasinya dihitung
dari posisi elemen di halaman.
